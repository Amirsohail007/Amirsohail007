### 🧠 About me

- 🏥 **Python Developer at Spry Health**, building LLM agents for US healthcare revenue-cycle management: prior authorization, claim denials, and ERA processing.
- 📈 Previously at **Lyxel & Flamingo**, built Amazon ad-tech: campaign automation, an LLM agent layer for bidding and budget pacing, and marketplace scraping pipelines.
- 🎯 I like **turning slow manual workflows into reliable agents**: typed outputs, guardrails, human-in-the-loop, and checkpointed state.

### 🚀 What I've built

| Project | What it does | Stack |
|---|---|---|
| **[ClewPath](https://clewpath.com)** | One browser capture → interactive product demo, AI-narrated video tutorial, and step-by-step written guide | FastAPI · LangChain · Gemini · Playwright · rrweb · Remotion · React |
| **Prior-Authorization Agent** | Stateful agent: RAG over payer policies → clinical-evidence extraction → portal form-fill → human review. Cut processing from **20 → 2 min per claim** | LangGraph · Pydantic AI · Playwright · Qdrant · Temporal |
| **Claim Denial & Appeals Agent** | Maps ERA (835) CARC/RARC codes to root causes, routes claims, drafts appeal letters | LangGraph · Pydantic AI · FastAPI |
| **Clinical Extraction Model** | Fine-tuned small model that emits schema-valid JSON (diagnoses, procedures, ICD-10) in place of API LLM calls | Qwen · LoRA · Pydantic |
| **JD Classifier** | Teacher–student distillation on 40K labeled job descriptions; **~93% accuracy at 2K+ inferences/day** | Gemini · Qwen · LoRA · BGE |
| **ERA Billing Automation** | Automated remittance processing and claim matching; **50–60% less manual review** | Python · FastAPI · ClaimMD |
